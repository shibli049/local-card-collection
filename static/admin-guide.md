# Import an existing folder

Use this guide when your photos are already in folders on your computer. Card Atlas calls this Connect folder. It reads the photos where they are and adds them to your collection.

For help with editing, moving photos or other tasks, go back to the collection and choose Getting started tour.

## Choose the main folder

Pick the folder that holds your albums and boxes. Card Atlas includes the folders inside it too. For example, you might have a main folder called My collection with Summer stamps and Box 01 inside it.

Keep the main folder somewhere you can leave it. Make a backup before you start if these are your only copies.

> Connecting a folder leaves your photos in place. Card Atlas saves their details in a file called `catalog.json` inside the main folder. Keep that file with your photos.

## Check the photo names

A paged album uses filenames ending in page, row and column numbers. For example, `stamp-2-3-1.jpg` means page 2, row 3, column 1.

A folder with no numbered photos becomes a box. If it contains numbered photos, it becomes a paged album. Plain filenames in a mixed folder have no position until you place them.

Check this before connecting the folder. Saved album and box types stay fixed. You can move photos to another album or box later if needed.

## Connect the folder

1. Sign in as an administrator.
2. Choose Connect folder beside Image folder.
3. Enter the full folder location. On a Mac it might look like `/Users/you/Pictures/My collection`. On Windows it might look like `C:\Users\you\Pictures\My collection`.
4. Choose Connect & scan and wait for the completion message.

If you are unsure how to find the full location, ask someone to help you copy it from your computer’s folder window.

Card Atlas connects one main folder per collection. If a folder is already connected, Connect folder is hidden. Use the existing collection or ask for help setting up a separate one.

## Check the imported photos

Choose Browse albums and open an album or box. Check that the photos you expected are there. The book icon means a paged album; the box icon means a box.

Open a photo to check its filename and position. Supported files are JPG, PNG, GIF, WebP, BMP, AVIF and ICO. A missing small preview does not always mean the photo is missing; try Open full image.

## Add more photos to the folder later

If you add or remove files outside Card Atlas, choose Reload from folder. The app checks the connected folder again. Avoid renaming or moving existing files outside the app, because their saved details may no longer follow them.

If the scan fails, check that the folder is still available and that Card Atlas can access it. For an external drive, make sure it is connected. Keep the error message if you need someone to help. Technical details are saved in the hidden `.log` folder beside your collection.
